# Mohammad Iftequaruddin — 3D Character Artist Portfolio (React)

A manga/fantasy-themed 3D character artist portfolio rewritten in **React 18**, **TypeScript**, and **Vite** with **Three.js**.

## Features

- **Interactive 3D Model Inspector (Three.js)**:
  - glTF / GLB model rendering with OrbitControls
  - Multi-shading modes: Shaded (procedural toon ramp), Base Color, Wireframe, Matcap, Normals, and UV checker
  - Real-time model statistics: Vertices, Triangles, Meshes, Materials, Format
  - Multi-character model switching, auto-rotation toggle, and view reset
- **Character Turntables**: 360-degree video reels with automatic hover/viewport playback
- **Categorized Portfolio Showcase**:
  - Featured Chapter: DIO Turnaround study
  - Character Art
  - Roblox UGC items & bundles
  - Game-ready Weapons & Props
  - Creatures & Mechanical Rigs
- **Interactive Lightbox**: Fullscreen inspection for high-resolution images and turntable videos with playback controls
- **Rigging & Unity Showcases**: Real-time avatar integrations, VTuber systems, and mechanical transform setups
- **Bizarre Dimension Audio Synth**:
  - Procedural 16-step Web Audio synthesizer with animated 5-bar equalizer and 'M' keyboard toggle
- **Motion Effects & SFX**:
  - Japanese SFX whisper stamps on interactive actions
  - Toggleable decorative animations
  - Stand Profile console ("Polygon Soul")
- **Profile, Career & Education**: About the artist, software skills, and career timeline

## Development

```bash
# Install dependencies
npm install

# Start Vite dev server on port 3000
npm run dev

# Build for production
npm run build
```
